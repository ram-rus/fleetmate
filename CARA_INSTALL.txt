LANGKAH 1 — SETUP DATABASE SUPABASE
================================================================
1. Buka supabase.com → login → pilih project fleetmate-mms
2. Klik SQL Editor (sidebar kiri)
3. Klik "New query"
4. Buka file: supabase/setup_fleetmate_v3.sql dengan Notepad
5. Ctrl+A (pilih semua) → Ctrl+C (copy)
6. Paste di SQL Editor Supabase
7. Klik tombol RUN (hijau, pojok kanan)
8. Tunggu muncul pesan:
   "Database FleetMate v3.0 siap digunakan!"

9. Jalankan juga migration workflow storing (WAJIB untuk fitur v3.1):
   - Buka file: supabase/migration_storing_workflow.sql
   - Copy semua → Paste di SQL Editor → RUN
   - Tunggu pesan: "Migration storing workflow v3.1 selesai!"

LANGKAH 4 — INSTALL DAN JALANKAN REACT
================================================================
1. Extract ZIP ini ke folder pilihan
   Contoh: D:\Projects\fleetmate

2. Buka Command Prompt (CMD) di folder "frontend":
   - Buka folder frontend di File Explorer
   - Klik address bar atas
   - Ketik: cmd
   - Tekan Enter

3. Jalankan perintah ini satu per satu:

   npm install

   (Tunggu selesai 2-5 menit)

   npm start

4. Browser otomatis terbuka ke: http://localhost:3000

TROUBLESHOOTING
================================================================
❌ "npm not recognized"
   → Install Node.js di nodejs.org (pilih LTS)
   → Restart CMD setelah install

❌ Halaman putih / error merah
   → Pastikan SQL sudah dijalankan di Supabase
   → Pastikan user sudah dibuat di tabel public.users

❌ HP tidak bisa buka aplikasi
   → Pastikan HP dan komputer WiFi SAMA
   → Cek IP komputer dengan: ipconfig
   → Pastikan npm start masih berjalan di CMD

❌ Login gagal
   → Cek SQL: SELECT * FROM public.users;
   → Pastikan UUID sudah diinsert dengan benar
